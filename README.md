# Deal Learning Tool (Hackathon)

Clickable prototype: pick a source owner, open a deal, and see context, pain points, milestones, EDI setup, signals and next steps, plus a per-deal chat.

All deal data in `index.html` is made-up demo data. The real tool would pull deals from Atlas (Pipedrive) and calls from Glyphic.

Run locally: open `index.html` in a browser. Deployed with Vercel (static site, no build step).
